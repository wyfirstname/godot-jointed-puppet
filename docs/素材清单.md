# 素材清单 · 部件交付规范

> 这份文档由 `python tools/asset_spec.py` 生成，尺寸/覆盖率/变体都是从
> `assets/parts/` 实测出来的。美术改完图重跑一次，表格自动跟着变。

## 0 · 一句话版本

**256×256 透明 PNG，地板线在 y=216，五个视图各一张，命名
`{槽位}_{变体}_puppet_{视图}.png`，染色遮罩同命名把 `puppet` 换成 `mask`。**
丢进 `assets/parts/{槽位}/`，跑 `tools/import_part.py`（可省）→
`tools/check_part.py` 验收 → `python tools/gen_character_designer.py` 上货架。

## 1 · 坐标系统（所有部件共用一张画布）

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | 256 × 256 RGBA | 不是 512，不是任意尺寸 |
| 地面线 | y = 216 | 脚底踩在这条线上；上下留 40px 给帽子/披风 |
| 竖直中轴 | x = 128 | 角色始终居中，不做左右偏移补偿 |
| 左右 | 屏幕左 = `l`，屏幕右 = `r` | 命名里的 l/r 说的是**屏幕**方向 |
| 缩放 | 1 单位 = 1 像素 | 不要给整张图做整体缩放，直接按像素画 |

## 2 · 五个视图，八个朝向

游戏里只存 5 张图，八个朝向靠**镜像**补出来：

| 朝向 | 0 S | 1 SW | 2 W | 3 NW | 4 N | 5 NE | 6 E | 7 SE |
|---|---|---|---|---|---|---|---|---|
| 用哪张 | s | sw | w | nw | n | nw 镜像 | w 镜像 | sw 镜像 |

两个后果，画之前就要想好：

1. **左右不对称的装饰会翻**。单边耳环、歪戴的帽子、左肩的肩甲，
   在 NE/E/SE 会跑到另一边 —— 要么接受，要么画成对称的。
2. **暗面朝向必须和 z 表的远近侧同侧**。sw/w 的暗面在屏幕右、nw 的在屏幕左，
   背面视图转过去了。`tools/check_parts.py` 会用像素把这条钉死，
   反了会出现「压暗的、变窄的那条胳膊压在身体前面」这种读不通的画面。

## 4 · 画法约束

| 要求 | 原因 |
|---|---|
| alpha 只有 0 或 255，边缘不羽化 | 遮罩和描边都靠硬边判定，半透明会串色 |
| 不要画投影 / 背景 / 环境光 | 影子由引擎按地面线自己画 |
| 每种材质至少 3 档明度（主色 / 暗部 / 高光） | 单色填充染色后是一块死色板 |
| 描边用统一深色（现为 `#382212`） | 描边不参与染色，靠它保持轮廓 |
| 关节处多画 2~3px 重叠 | 转起来才不会露缝（`tools/check_joint_gap.py` 查这个） |
| 部件不要贴到画布边缘 | 贴边说明尺寸超了，转视角会被裁 |
| 同一槽位的所有变体，挂点位置一致 | 换装时部件不能跳位 |

## 5 · 染色遮罩（决定这件东西能不能改色）

遮罩是同样尺寸的 PNG，用纯色标出「这块像素吃什么颜色」：

| 像素值 | 含义 |
|---|---|
| `(255, 0, 0)` 纯红 | 主色区：跟着木头/布料/头发色板走 |
| `(255, 255, 0)` 黄 | 皮肤区：跟着肤色走 |
| `(255, 0, 255)` 品红 | 金属区：跟着金属色走 |
| 全透明 | 不染色，保持美术原色（描边就该在这里） |

**R 通道是总开关**：shader 最后一步是 `mix(base, c, mask.r)`，
R=0 的像素不管 G/B 写什么都没用 —— 金属区曾经写成 `(0,0,255)`，
结果金属调色被整个丢掉，验证图三行长得一模一样。所以遮罩内可见像素 R 必须 255。

两条做法，选一条：

- **A. 交给工具**：`import_part.py --metal-colors ...` 按色距自动分类。
  金属/皮肤之外全部算主色；想让描边免染就手绘遮罩（自动判描边容易误伤深色布料）。
- **B. 手绘遮罩**：另存一张同尺寸图，用上面三种纯色刷出区域。最准，
  适合金属件、皮肤露出的部件。

## 6 · 进场流程

```bash
# 1) 收图：自动裁到画布、对齐挂点、生成遮罩（--pivot 是图上要对到关节的那个点）
python tools/import_part.py --art 我的长袍.png --slot body --variant robe \
       --view s --pivot 300,180 --scale 1.0

# 2) 验收：五个视图齐不齐、尺寸/挂点/遮罩/基色对不对
python tools/check_part.py --slot body --variant robe

# 3) 上货架：重打包角色设计器，页面里立刻多一套
python tools/gen_character_designer.py
```

五张视图都要跑一次第 1 步（`--view s/sw/w/nw/n`）。

## 7 · 交付前逐项打勾

```
[ ] 5 个视图齐全：s / sw / w / nw / n
[ ] 每张 256×256，RGBA，背景全透明
[ ] 脚底落在 y=216，中轴 x=128，没有任何一边被裁
[ ] 挂点和骨架对得上（表 3 的挂点列）
[ ] 同一槽位所有变体的挂点、整体大小一致
[ ] 每种材质有 3 档明度，不是单色平涂
[ ] 暗面方向和现有素材同侧（跑 check_parts.py 不报错）
[ ] 遮罩齐全、R=255、描边没被标成可染
[ ] 关节处有 2~3px 重叠，不露缝
[ ] check_part.py 通过
```

## 8 · 常见退回原因

1. **尺寸不是 256，或四个视图尺寸不一致** —— 统一画布是整套对齐的前提。
2. **挂点漂移** —— 头饰按包围盒居中贴，结果每个变体帽子位移不一样，换装就跳。
3. **贴边** —— 边长 256 或 bbox 到 0/255，转视角直接被裁。
4. **半透明边缘** —— 遮罩判定失准，染色后一圈脏边。
5. **单色平涂** —— 染色能上色，但看起来像贴纸。
6. **遮罩把描边也标了** —— 整圈轮廓跟着变色，暗棕被拉成亮色，边缘糊掉。
7. **遮罩 R=0** —— 看着写了颜色，实际一点没染（最隐蔽的一条）。
8. **暗面朝反** —— 3/4 视图里远近侧和 z 表打架。
9. **只交正视图** —— 一转身发现侧面是空的。
10. **不对称装饰** —— 镜像视图里跑到另一边，除非你本来就要这个效果。

## 9 · 想加一个全新槽位（不是新变体）

新变体只要放图；**新槽位**要改四处，漏一处就会出现「图在但游戏里不显示」：

| 步骤 | 文件 | 改什么 |
|---|---|---|
| 1 | `data/layer_rules.json` → `z` | 五个视图各给一个 z 值 |
| 2 | `data/layer_rules.json` → `_rig.slot_joint` | 槽位挂哪个关节 |
| 3 | `core/character/joint_doll.gd` | 若背面要换层，进 `Z_ON_BACK` |
| 4 | `core/data/character_visual.gd` | 要默认穿戴就进 `DEFAULT_SLOTS`；
   |  | 进 `tools/gen_character_designer.py` 的 `GROUPS` 才能被色板染 |

改完跑：`godot --headless --path . --script tools/dump_layers.gd` 刷新 `_rig`，
再 `python tools/gen_character_designer.py`。
